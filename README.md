# SimpleConverter

Приложение для конвертации единиц измерения и расчёта площади/периметра квадрата и прямоугольника.

## Функции:
- Метры ↔ сантиметры, минуты ↔ секунды
- Площадь и периметр квадрата
- Площадь и периметр прямоугольника
- Копирование результата
- Проверка корректности ввода
- Локализация (русский и английский)

## Технологии:
Android Studio, Material Design, ViewModel + LiveData
